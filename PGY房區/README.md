# PGY房區表自動化

`pgy_room_schedule.py` 會讀「CR排課」和「主治醫師房區表」，產生當月的 PGY房區表並自動排班。整個流程在 Google Colab 執行，只會新增一份試算表，**原本的 CR排課、主治醫師房區表、PGY房區表都只讀不寫**。

---

## 每月使用步驟

1. 開 Colab，把整份程式貼進一個儲存格。
2. 修改參數區（Cell 2）的 `TARGET_TAB`，改成當月年月，例如 `"202611"`。
3. 執行。第一次會跳出 Google 帳號授權，請允許。接著：
   1. 確認國定假日：程式列出從 CR 月曆偵測到的平日假日，按 Enter 採用，或自己輸入日期。
   2. 程式建立新試算表「`YYYYMM PGY房區表`」（放在你的 Drive 首頁），印出網址後暫停。
   3. 打開表檢查格式、特休、淡水日期，有需要直接在表上修改。
   4. 回 Colab 按 Enter，程式讀回表上的內容排班，結果**覆寫在同一份表**上。
4. 檢查紅色格子（程式排不出來的），手動補上。

> 程式裡的 `# Cell N` 只是分段標示。想分開貼也可以（例如只改參數不用重跑授權），但不是必要。

### 只想重排（不重新產生初始表）

把那份表的 ID（網址 `/d/` 和 `/edit` 中間那串）貼到參數區的 `EXISTING_SHEET_ID`，再執行一次。程式會跳過產生初始表，直接等你按 Enter 排班。這時如果有平日國定假日，請自己填在 `NATIONAL_HOLIDAYS`；表上灰色的日子也會被當成假日。

## 資料來源

| 表格 | 用途 | 讀取內容 |
|---|---|---|
| CR排課 | PGY名單、特休、國定假日 | A欄「PGY」那列以下：員編、姓名、級別、導師(上)、導師(下)、特休；上方月曆「北/淡」列中寫著放假、補假的平日 |
| 主治醫師房區表 | 每天各房區的主治醫師 | 第2列為房區標題，第3列起為每天。「台北白班」(含)以前是台北房區，跳過兩欄日期鏡像欄後是淡水房區 |

三份表的分頁都用同樣的年月命名，例如 `202610`。

---

## 產生出來的表格格式

| 列 / 欄 | 內容 |
|---|---|
| 第1列 | 職級（最右欄為「備註」） |
| 第2列 | 員編 |
| 第3列 | 姓名 |
| 第4列 | 導師(上半月) |
| 第5列 | 導師(下半月) |
| 第6列起 | A欄日期（如 2026/10/1）、B欄星期、C欄起各 PGY，PGY1 在左、PGY2 在右 |

### 顏色說明

| 顏色 | 意思 | 誰標的 |
|---|---|---|
| 灰 | 週末、平日國定假日 | 初始表自動標 |
| 黃 | 特休 | 初始表自動標（依 CR 特休欄） |
| 淺藍 | 淡水指定日 | 初始表自動標，可手動修改 |
| 金黃 | PCA 日 | 排班結果 |
| 淺紅 | 麻評門診 | 排班結果 |
| 橘 | 病房評估 | 排班結果 |
| 紅 | 排不出來，需手動處理 | 排班結果 |

排班時程式是**看顏色**判斷狀態的，所以手動修改初始表時，請用上面這幾種顏色。程式會容許些微色差。

## 排班規則

### 初始表
- **特休**：讀 CR 的特休欄，支援常見寫法，例如 `10/23`、`10/19、10/21`、`10/16-17`、`9/12, 27`、`3/27. 28`、`7.14`、`11/21(ACLS公假)`。沒寫月份的數字沿用前一個月份。無法辨識的片段會在畫面上提醒。
- **假日**：週末加上你確認過的平日國定假日，整列標灰，假日名稱寫進備註欄。
- **淡水週**：
  - 最後一個工作天的**前一週**：後半部 PGY 去淡水。
  - **再前一週**：前半部 PGY 去淡水。
  - 前後半部依表上左到右的順序分，人數是奇數時前半部多一人。
  - 只標工作天；假日維持灰色，特休維持黃色。

### 排班
- **麻評門診**：依表上左到右的順序輪流，每人一次。PCA 日、最後工作天、假日不排。
- **台北房區**：
  - 第一輪先配給自己的導師，前兩週還沒遇過導師的人優先。
  - 第二輪隨機配，並檢查導師互斥。
  - 同一位主治醫師一天只配給一位 PGY（台北、淡水合計）。
- **淡水指定日**：從淡水房區的主治醫師中隨機挑，同樣檢查導師互斥。
- **病房評估**：
  - 只從當天有配到台北房區、而且已經上過麻評門診的人選。
  - 每人最多 3 次，先補還沒滿 2 次的人；大家都滿 2 次之後優先 PGY2；平手時隨機。
  - PCA 日、最後工作天、假日後第一個工作天不排。
- **PCA 日**：當月第一個工作天，當天配到房區的格子標金黃。
- **重跑結果固定**：同一份輸入重跑，結果完全一樣。想換一組組合，改 `RANDOM_SEED` 的數字。

## Cell 2 參數

| 參數 | 說明 |
|---|---|
| `TARGET_TAB` | 當月分頁名稱（年月），每月必改 |
| `NATIONAL_HOLIDAYS` | `None`＝自動偵測後讓你確認；也可直接填，例如 `[9, 26]`，沒有就填 `[]` |
| `EXISTING_SHEET_ID` | 只想重排時，貼上既有表格的 ID |
| `DANSHUI_AUTO` | `True`＝自動標淡水週；`False`＝全部手動 |
| `DANSHUI_WEEK_MODE` | `"calendar"`＝以週一到週日為一週；`"rolling"`＝從最後工作天往前推 7 天 |
| `TAIPEI_HARD_EXCLUDE_KEYWORDS` / `DANSHUI_HARD_EXCLUDE_KEYWORDS` | 房區標題含這些字就整欄不排；前面加 `=` 表示標題完全相同才排除，例如 `"=特"` |
| `MENTOR_CONFLICT_PAIRS` | 導師互斥配對（雙向），例如 `[("黃雅嫻", "楊承憲")]` |
| `RANDOM_SEED` | 亂數種子，改數字可得到不同排法 |
| `DEBUG_WARD_EVAL` | `True`＝印出每次病房評估的決策過程 |
| `CR_SHEET_ID` / `ATTENDING_SHEET_ID` | 來源表格 ID，通常不用改 |

## 常見問題

**CR排課找不到 PGY？**
程式是在 A 欄找內容剛好是「PGY」的那一格。請確認標題沒有被改成其他字，例如「PGY名單」。

**特休日期不對？**
看畫面上「特休：」那段印出的日期，和 CR 原文對照。寫法太特殊的話，直接在初始表上手動塗黃即可。

**某個房區不該排卻被排了／該排卻被排除？**
畫面會印出台北、淡水各被排除哪些房區，請調整 Cell 2 的排除關鍵字。

**出現紅色格子？**
代表當天可用的房區不夠，或剩下的主治醫師都和該 PGY 導師互斥，請手動處理。

**重開 Colab 後要繼續排？**
把表格 ID 填到 `EXISTING_SHEET_ID`，再重新執行一次。
