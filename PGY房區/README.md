# PGY房區表自動化

用 Python(Google Colab)讀取「主治醫師房區表」跟「PGY房區表」兩份 Google Sheet,套用排班規則,自動產生下個月的 PGY 房區分配,輸出成一份新的 Google Sheet。

## 使用方式

1. 打開 `pgy_schedule_engine.py`,把內容依 `# Cell N` 的分段,依序貼到 Colab 的不同儲存格。
   （這樣分段純粹是方便偵錯、確認中間結果，不是技術上的限制——你也可以把整份檔案內容一次貼到**同一個**儲存格執行，效果完全一樣。）
2. **Cell 2** 是每個月要跑之前需要確認的參數,至少要改 `TARGET_TAB`(分頁名稱,例如下個月是 `202611`)。
3. 從 **Cell 1** 開始依序整個執行到 **Cell 10**(或一次貼上整份執行)。Cell 1 會跳出 Google 帳號登入授權視窗。
4. Cell 9 執行完會印出每位 PGY 的統計結果(麻評門診/病房評估次數、導師碰面次數)。
5. Cell 10 執行完會印出一個新 Google Sheet 的連結,**建立在你 Google Drive 的根目錄**,不會動到原本任何表格。打開來核對後,自己手動複製到正式表格。

## 前置需求

- 兩份表格都要用你自己的 Google 帳號能開啟(檢視或編輯權限皆可),而且**兩份表格的分頁命名規則要一致**(用年月當分頁名稱,如 `202610`)。
- Colab 執行環境需要能對你的 Google 帳號做 OAuth 授權(`google.colab.auth`),多數 Colab 環境預設就支援。

## 輸入表格的格式慣例

### 主治醫師房區表(每月一個分頁)
- 第2列:各欄標題(值班V/門診+碎石/.../台北白班/1~5.../白班R-特)
- 第3列起:逐日資料。A欄=日期數字,C欄起到「台北白班」欄(含)=台北房區,接著兩欄是日期鏡像欄(自動跳過),再來才是淡水房區欄位
- 欄位數量每個月可能不同(排除關鍵字用**文字比對**,不是寫死欄位字母)

### PGY房區表(每月一個分頁)
- 第1列=職級(PGY1/PGY2)、第2列=員編、第3列=姓名、第4列=導師(上)、第5列=導師(下)
- 第6列起:A欄=完整日期(`YYYY/MM/DD`)、B欄=星期、C欄起=各PGY當天內容、標題為「備註」的欄位=備註
- **顏色慣例**(程式會自動判斷,不用手動對照):
  | 顏色 (RGB) | 意義 |
  |---|---|
  | 淺藍 `(0.812, 0.886, 0.953)` | 使用者手動標記的淡水指定日 |
  | 灰 `(0.8, 0.8, 0.8)` | 週末/國定假日(整天所有PGY欄位都是灰色) |
  | 黃 `(1, 1, 0)` | 個人休假 |
  | 金黃 `(0.988, 0.839, 0.408)` | PCA訪視教學(通常只出現在月初第1天) |
  | 鮭紅 `(0.902, 0.722, 0.686)` | 麻評門診(程式輸出用,原始表格通常沒有) |
  | 橘 `(1, 0.655, 0.4)` | 病房麻醉評估(程式輸出用) |
- 個人休假也可能直接用文字打「休假」兩個字,程式會同時用文字跟顏色雙重判斷。

## 排班規則總覽

每天依序判斷:

1. **休假**(文字是「休假」或灰/黃底色)→ 不排任何東西,原封不動照抄原本的文字跟顏色
2. **月初第1天(PCA訪視教學)** → 只排房區,不排麻評門診/病房評估
3. **淡水指定日**(使用者手動標淺藍色的PGY)→ 從淡水房區找可用醫師(排除硬性清單、導師互斥、當天已被別人選走的醫師)
4. **麻評門診**:每人每月一次,全院同一天限一人,固定依 PGY 表格左到右欄位順序輪流指派(不看任何次數),月初首日跟月底最後一天不排
5. **病房評估**:需先排過麻評門診、每人每月2-3次、全院同一天限一人;優先給累積次數最少者,大家都滿2次後改優先給PGY2(同樣再依次數最少排序,還是平手就隨機);**假日後第一個工作天**(用PGY表格灰色判斷)不排
6. **台北一般房區**:排除硬性清單(值班/門診+碎石/VS-Room-7/台北白班/二線)後,剩下的醫師先以姓名去重(同一人可能同時掛在多個房區欄位),優先分給「今天剛好有自己導師房區、且還沒在前兩週遇過導師」的PGY,其餘隨機配對,並檢查導師互斥規則(黃雅嫻/楊承憲互斥)

全天(不分台北/淡水)**同一位醫師只能配給一位PGY**,不會重複。

### 軟性目標(排序時盡量兼顧,不是硬性規則)
- 每位PGY每月盡量跟自己導師(上+下半月合計)碰面超過4次
- 麻評門診盡量在月初早一點排完

## 需要人工檢查的地方

程式如果排不出來會印出 `[警告]` 訊息,同時輸出表格裡那一格會塗成**紅色**,提醒你手動處理,常見情況:
- 淡水指定日當天所有淡水醫師都被導師互斥規則排除,或都被同天其他人選走
- 台北房區當天可用醫師數不夠分配給剩下的人

## 調整選項(Cell 2)

- `RANDOM_SEED`:固定的話,重跑結果都一樣;改成別的數字會得到不同的隨機分配結果
- `DEBUG_WARD_EVAL`:設成 `True` 會印出每次病房評估決策的詳細候選名單、篩選邏輯、最終選中的人,方便追查分配是否合理
- `TAIPEI_HARD_EXCLUDE_KEYWORDS` / `DANSHUI_HARD_EXCLUDE_KEYWORDS`:排除清單,每個月如果有調整可以直接改這裡
- `MENTOR_CONFLICT_PAIRS`:導師互斥配對清單,要新增其他互斥組合可以直接加進這個 list
